# 個別株・ファンド分析システム(stock_analyzer)

> ⚠️ **免責**: 本ツールは個人が作成した分析ツールで、投資助言・売買の推奨ではありません。表示される点数・所見は
> 外部データ(Yahoo Finance・JPX・Wikidata・投信総合検索ライブラリー等)に基づく機械的な参考値で、遅延や誤りを含む
> ことがあります。投資判断はご自身の責任で行ってください。

個別株(日本株・米国株)のファンダメンタル分析とテクニカル分析、および投資信託(楽天証券で
買えるファンド)の分析を行い、点数化して総合所見を出す独立システム。分からない点はシステム内で
質問できる。投資判断支援システム(investment_system)
とは別物で、コード・設定・出力・venv を共有しない。

**すること**
- Yahoo Finance(yfinance)から年次決算(最大5期)・配当履歴・5年日足を取得
- ファンダメンタルスコア(100点): 成長性・収益性・財務健全性・割安度・株主還元 各20点
- テクニカル: 移動平均(5/25/75/200)・RSI・MACD・ボリンジャー・ATR・52週高安・出来高・支持/抵抗線から
  トレンド強度スコア(100点)と売買タイミング区分(押し目/過熱/売られすぎ/中立)
- 両者を掛け合わせた総合所見、適正株価の参考レンジ、自動判定できないリスク項目
  (特別損益・のれん・流動性・大株主集中など)
- ウォッチリスト一括スキャン、Markdownレポート保存

**しないこと**: 売買の実行・銘柄の推奨。業種を問わず同じ物差しで採点する機械的な参考値であり、
同業比較やビジネスモデルの評価は含まない。最終判断は利用者が行う。

## 構成

```
stock_analyzer/
  analysis.py   分析エンジン(財務テーブル・採点・テクニカル指標・総合所見)
  fetchers.py   yfinance取得(OHLCV・企業プロファイル・財務三表・配当)
  cache.py      ディスクキャッシュ+リトライ
  config.py     パス・watchlist.yaml・settings.yaml の読み書き
  report.py     Markdownレポート生成
  resolver.py   コード・社名・ティッカーの解決(JPX上場銘柄一覧 + Wikidata米国企業リスト + Yahoo検索)
  funds.py      投資信託のデータ取得(投信総合検索ライブラリー: 検索・属性・基準価額CSV)
  fund_analysis.py 投資信託の採点・所見
  fund_report.py / fund_view.py 投資信託のレポート・表示
  assistant.py  質問機能(Anthropic API / Claude Code CLI)
  view.py       Streamlit用の描画(チャート・表)
  app.py        Streamlitダッシュボード(port 8766)
  cli.py        コマンドライン実行(kabu ランチャーから呼ばれる)
  kabu          ターミナル用ランチャー
  install/      venv作成・LaunchAgent登録スクリプト
```

実データはすべて `~/Dropbox/buzzraseya/銘柄分析/` 配下(GitHubには同期されない):

```
銘柄分析/
  config/watchlist.yaml       ウォッチリスト(ticker / name / note / shares / avg_cost)
  config/settings.yaml        閾値の上書き(任意。settings.example.yaml を参照)
  config/recent.json          最近調べた銘柄(自動更新)
  config/secrets.yaml         APIキー(任意。secrets.example.yaml を参照)
  質問ログ/YYYY-MM.md          質問と回答のログ
  reports/{ticker}_{日付}.md   分析レポート
  cache/                      yfinanceのキャッシュ(株価6時間・財務24時間)
```

## Web公開版(Streamlit Community Cloud)

このリポジトリをそのまま Streamlit Community Cloud にデプロイすると、URLを共有するだけで誰でも使える。
オーナー環境以外では自動的に「共有モード」になる:

- ウォッチリスト・最近調べた銘柄は利用者ごとにブラウザのセッション内だけで保持(サーバーに保存しない)
- レポートは保存ではなくダウンロード、質問ログも残さない
- 質問機能は、Cloud の Secrets に `anthropic_api_key = "sk-ant-..."` を設定すれば全員が使える(オーナー負担)。
  未設定なら利用者が自分のAPIキーを入力して使う(セッション内のみ)
- 画面上部に免責を表示

デプロイ手順: https://share.streamlit.io にGitHubでログイン → Create app → リポジトリ `suesugi60/stock-analyzer`、
ブランチ `main`、メインファイル `app.py`、Python 3.12 → Deploy。オーナーのMacから公開リポジトリへ反映するには
`bash publish_public.sh`。

## すぐ調べる(クイック検索)

ダッシュボード最上部の検索欄に **証券コード・社名・ティッカー** のどれを入れても Enter で即分析する。

| 入力例 | 動き |
|---|---|
| `7203` / `7203.T` | 日本株コード → トヨタ自動車をそのまま分析(社名はJPX上場銘柄一覧から補完) |
| `トヨタ` | 社名の部分一致 → 候補(トヨタ自動車・トヨタ紡織…)を表示して選ぶ |
| `任天堂` | 候補が1件なら即分析 |
| `AAPL` / `Toyota` | 米国ティッカー / 英語名 → Yahoo検索で解決 |
| `アップル` / `エヌビディア` / `グーグル` | 米国企業のカタカナ名 → Wikidata由来の企業リスト(日本語名・別名、30日キャッシュ)で解決 |
| `オルカン` / `楽天 全米` | 投資信託 → 投信総合検索ライブラリーで検索(🏦印) |

- URLに `?t=` を付けても開ける: `http://localhost:8766/?t=任天堂`(ブックマークやランチャー登録向け)
- 「最近調べた銘柄」「ウォッチリスト」はワンクリックで再表示。分析結果から「ウォッチリストに追加」もできる
- 社名検索の辞書はJPX「東証上場銘柄一覧」(約4,000銘柄、7日キャッシュ)。取得できない時はYahoo検索のみで動く
- ターミナルからは `kabu` ランチャーで同じことができる:
  ```bash
  alias kabu="$HOME/Dropbox/buzzraseya/scripts/stock_analyzer/kabu"   # ~/.zshrc に追加
  kabu トヨタ            # 候補表示
  kabu 任天堂 7203 AAPL  # 即分析(レポート保存)
  kabu --search ソニー   # 候補だけ
  ```

## 投資信託(ファンド)の分析

検索欄にファンド名(の一部)を入れると投信の候補も出る(🏦印)。例: `オルカン` `楽天 全米` `SBI・V` `インド Nifty`。
ISIN(`JP90C000H1T1`)でも直接開ける。

- データ: 投信総合検索ライブラリー(資産運用業協会)。信託報酬・純資産・期間リターン・リスク・シャープレシオ・
  同分類内順位・決算頻度・分配金・NISA対象・販売会社一覧(=**楽天証券での取扱有無**)+設定来の基準価額CSV
- スコア(100点): コスト25 / 規模・資金流入20 / リターン25 / リスク効率20 / 継続性・安全性10
- 計算値: 分配金再投資ベースのトータルリターン、年率変動率、最大下落率、純資産の増減、分配金利回り
- リスク検出: 小規模(繰上償還)、運用年数不足、高コスト、毎月分配(タコ足)、資金流出、高ボラ、評価乖離、楽天証券取扱なし
- 楽天証券のファンドページ・運用会社の月次レポートへのリンクを表示
- 投信協会の期間リターン・順位は月末基準、計算値は最新基準日ベースなので数値に差が出ることがある

## 質問機能(Q&A)

分析結果の下の「💬 この銘柄について質問する」で、用語の意味・スコアの根拠・リスクの見方などを
そのまま聞ける(分析レポート全文を文脈として渡す)。CLIでは `kabu 7203 --ask "PERは高い？"`。
回答の生成は次のどちらかを自動で使う:

1. Anthropic API: `銘柄分析/config/secrets.yaml` に `anthropic_api_key` を設定(従量課金。モデルは
   settings.yaml の `qa_model`、既定 `claude-opus-5`)
2. Claude Code CLI: ターミナルで `claude login` 済みならサブスクリプションで動く(追加費用なし)

会話ログは `銘柄分析/質問ログ/YYYY-MM.md` に残る。

## 採点の考え方

| カテゴリ | 主な項目 | 満点の目安 |
|---|---|---|
| 成長性 | 売上高CAGR・営業利益CAGR・直近期の増収増益 | 年率15%以上 |
| 収益性 | ROE・営業利益率・利益の質(営業CF>純利益) | ROE20%・営業利益率20% |
| 財務健全性 | 自己資本比率・有利子負債の重さ・流動比率・FCF | 自己資本比率60%・ネットキャッシュ |
| 割安度 | PER・PBR・過去5期のPERレンジとの比較 | PER10倍以下・PBR1倍以下・過去比で下位25% |
| 株主還元 | 配当利回り・配当性向・連続増配 | 利回り4%・性向30〜60%・3期連続増配 |

トレンド強度(100点)は移動平均の位置と配列・200日線の向き・MACD・52週高値からの距離・
指数(日経平均/S&P500)に対する相対強度・RSI・出来高で採点する(高いほど上昇トレンドが強い)。
タイミングはRSIとボリンジャー%Bで「過熱」「売られすぎ」を、上昇トレンド内の25日線割れを「押し目」と判定する。

## データの注意

- 株価は auto_adjust=False(分割は調整済み・配当落ちは未調整)で取得し、実際の株価水準のまま
  期末PER・52週高安・支持線を計算する
- 年次決算ベースなので直近の四半期決算は反映されない。小型株は予想PER・アナリスト目標株価が無いことが多い
- ETF・投資信託は財務諸表が無いためテクニカルのみで所見を出す
