# 役名コールの音声ファイル置き場

ここに下の名前で音声ファイルを置くと、サイコロが止まったときにその声で役名をコールします。
置いていない役は、端末の読み上げ機能(自動でいちばん自然な日本語の声を選ぶ)で読み上げます。
全部そろえなくても、置いたものから順に使われます。

- 形式: `.mp3` または `.m4a`(iPhone の「ボイスメモ」で録ったままの形式)。同じ名前で両方ある場合は `.mp3` を使います。
- 長さの目安: 1〜2秒。頭の無音は短く切ると気持ちよく鳴ります。
- 音量: 他の効果音に埋もれないよう、少し大きめに録ると良いです。

| ファイル名 | 役 | 言う内容の例 |
|---|---|---|
| `pinzoro` | ピンゾロ(1・1・1) | 「ピンゾロ!」 |
| `zoro2` 〜 `zoro6` | ゾロ目(2〜6) | 「2ゾロ!」…「6ゾロ!」 |
| `shigoro` | シゴロ(4・5・6) | 「シゴロ!」 |
| `me1` 〜 `me6` | 通常の目(1〜6) | 「1の目」…「6の目」 |
| `none` | 目なし | 「目なし」 |
| `hifumi` | ヒフミ(1・2・3) | 「ヒフミ…」 |
| `shonben` | ションベン(器から飛び出し) | 「ションベン!」 |

例: `voice/pinzoro.m4a`、`voice/me5.mp3` のように置きます(拡張子以外は小文字・半角)。

## 自分の声で録る(いちばん盛り上がります)

1. iPhone なら「ボイスメモ」、Android なら「レコーダー」で 19 個をひとつずつ録音します。
2. 共有 → ファイルに保存 などで取り出し、上の表の名前に変えます(例: `pinzoro.m4a`)。
3. このフォルダ(`chinchiro/voice/`)に入れて、いつもの手順で公開します(Dropbox 側にも忘れずに)。

## 合成音声を使う(VOICEVOX など)

無料ソフト VOICEVOX(ずんだもん等)で文言を入力して書き出した `.wav` を `.mp3` に変換して置けます。
キャラクターごとの利用規約(クレジット表記が必要なものがあります)に従ってください。
