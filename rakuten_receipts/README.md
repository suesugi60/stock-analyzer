# 楽天トラベル領収書一括ダウンロード

楽天トラベルの過去の国内宿泊予約について、領収書を同じ宛名でまとめて発行し、PDF として保存するツールです。
手元の Mac でブラウザを自動操作します。ログインは自分の手で行い、パスワードはこのツールに渡しません。

対象は**国内宿泊のオンラインカード決済**の予約だけです。現地決済(領収書は宿が発行)、楽パック、レンタカー、海外宿泊は扱いません。

## 注意

- **宛名の修正は1回限りです。** 楽天トラベルの決まりで、発行した領収書の宛名は1回しか直せません。
  このツールは最初の1件を発行する直前で止まり、ブラウザの確認画面を目で見てから進めるようになっています。
  修正の機能は使いません。
- **利用は自己判断です。** 楽天の規約が自動操作を禁じているかどうかは確認できていません。
  人と同じ手順を、1件ずつ数秒おきにたどるだけの作りにしてあります。
- **本物の画面では未検証です。** 作成時にログイン後の画面を確認できなかったため、公式ヘルプに出てくる文言
  (「領収書発行」「領収書の発行」「発行する」)を手がかりに作ってあります。初回は調整が要る見込みです。
  画面が想定と違うときは、何も押さずに止まります。

## セットアップ(Mac)

Python 3.9 以上が必要です。リポジトリのルートで実行します。

```bash
python3 -m venv .venv
```

```bash
.venv/bin/pip install -r rakuten_receipts/requirements.txt
```

Google Chrome が入っていればそれを使います。入っていない場合だけ、次も実行します。

```bash
.venv/bin/python -m playwright install chromium
```

## 使い方

3段階で進めます。どのコマンドでも Chrome が開くので、ログインし、予約確認の「国内宿泊」で
**過去の予約一覧の1ページ目**を表示してから、ターミナルで Enter を押してください。

### 1. 一覧を出す(何も発行しません)

```bash
.venv/bin/python -m rakuten_receipts list --from 2025-01-01 --to 2025-12-31
```

出力先の `receipts.csv` を開き、実際の履歴と合っているか確認します。

### 2. 1件だけ発行する

```bash
.venv/bin/python -m rakuten_receipts download --from 2025-01-01 --to 2025-12-31 --name "株式会社サンプル" --title 御中 --limit 1
```

確認画面で止まるので、ブラウザで宛名を確認し、よければ `y` を入力します。保存された PDF を開いて中身を確認します。

### 3. 残りを発行する

```bash
.venv/bin/python -m rakuten_receipts download --from 2025-01-01 --to 2025-12-31 --name "株式会社サンプル" --title 御中
```

取得済みの予約は飛ばします。途中で止めても、同じコマンドで続きから再開できます。

### 全部を1つにまとめたファイル

`download` が終わるたびに、取得済みの領収書をチェックイン日の古い順に結合した `領収書まとめ.pdf` を出力先に作ります。
個別の PDF もそのまま残ります。PDF ビューアのしおりから、目的の領収書へ飛べます。

まとめファイルだけを作り直したいときは、次を実行します(ブラウザは開きません)。

```bash
.venv/bin/python -m rakuten_receipts merge
```

まとめファイルに入るのは、出力先の台帳で「取得済み」になっている全件です。`--from` / `--to` では絞りません。
年ごとに分けたいときは、`--out` で出力先を分けてください。

### 引数

| 引数 | 使える場面 | 意味 |
|---|---|---|
| `--from` / `--to` | list・download | チェックイン日での絞り込み(両端を含む)。省略すると履歴にある全件 |
| `--out` | すべて | 出力先のフォルダ。既定は `~/Documents/rakuten-receipts/` |
| `--name` | download | 宛名。必須。50文字まで。半角記号と環境依存文字(㈱ 髙 など)は使えません |
| `--title` | download | 敬称。`様` か `御中`。必須 |
| `--limit` | download | 今回処理する最大件数 |

## 保存されるもの

出力先(既定 `~/Documents/rakuten-receipts/`)に次のものができます。

- **領収書の PDF**: `2025-03-15_ホテル名_予約番号.pdf`(日付はチェックイン日)。同名のファイルがあれば上書きせず、末尾に番号を付けます。
- **`領収書まとめ.pdf`**: 取得済みの領収書を1つに結合したものです。`download` のたびに作り直します。
- **台帳 `receipts.csv`**: 予約ごとの状態です。Excel でそのまま開けます。
- **`debug/`**: うまくいかなかった画面の記録(後述)。

台帳の「状態」の意味は次のとおりです。

| 状態 | 意味 | 次に `download` したとき |
|---|---|---|
| 未取得 | 一覧にあり、「領収書発行」がある | 対象 |
| 取得済み | PDF を保存した | 飛ばす |
| 対象外 | 「領収書発行」がない(現地決済など) | 飛ばす |
| 要確認 | 想定外の画面だったので何もしなかった | もう一度試す |
| 失敗 | 発行する前の段階でエラーになった | もう一度試す |
| 失敗(発行後) | 発行は済んだ可能性があるが、PDF を保存できなかった | もう一度試す(発行済みとして扱われます) |

「失敗(発行後)」になったときは、その場で実行を止め、ブラウザを開いたままにします。手で保存してから Enter を押してください。
手で保存した PDF は台帳に載らないので、そのままでは `領収書まとめ.pdf` に入りません。
次に `download` を実行すると、発行済みの領収書として保存し直し、まとめにも入れます。

ログイン状態は `~/Library/Application Support/rakuten-receipts/profile` に保存されます(普段使いの Chrome とは別です)。
ログイン情報を消したいときは、このフォルダを削除してください。

## うまく動かないとき

想定した画面や要素が見つからないと、その画面のスクリーンショット(`.png`)と HTML(`.html`)を
出力先の `debug/` に残して、何も押さずに止まります。想定外のエラーの場合は `debug/` に `…_error.txt` も残します。

- **これらのファイルには氏名・予約番号・金額などの個人情報が含まれます。** このリポジトリは公開されているので、
  絶対にコミットしないでください。人に見せるときは、先に中身を確認してください。
- 直すときに必要なのは、ボタンやリンクの文言と、その周辺の HTML です。
  画面の文言とセレクタは `rakuten_receipts/site.py` の先頭にまとめてあります。
- 「予約一覧のタブが見つかりません」と出るときは、過去の予約一覧を表示したタブが開いているか確認してください。
- 3件続けて要確認・失敗になると、画面構成が想定と違うとみなして全体を止めます。

## 配布上の注意

`publish_public.sh` は Dropbox 側の元フォルダから `rsync --delete` で公開リポジトリへ同期します。
GitHub 側にだけ `rakuten_receipts/` を置くと、次回の同期で削除されます。
元フォルダにも `rakuten_receipts/` と `docs/` をコピーしておいてください。

## テスト

```bash
.venv/bin/pip install -r rakuten_receipts/requirements-dev.txt
```

```bash
.venv/bin/python -m pytest rakuten_receipts/tests -q
```

テストは `tests/fixtures/` のダミーページに対して行います。本物の楽天には接続しません。
保証できるのは「想定した画面構成に対して正しく動くこと」までです。
