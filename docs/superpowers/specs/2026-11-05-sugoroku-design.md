# 飲みスゴロク 設計書

作成日: 2026-11-05

## 目的

飲み会の場で、1台のスマホ(またはPC)を回しながら遊ぶ「飲みスゴロク」。
サイコロを振って駒を進め、止まったマスの指令(飲む系)を実行する。
アプリはサーバー不要の単一HTMLファイルで、ネットがなくても動く。

本リポジトリ(stock-analyzer)は株式分析ツールだが、利用者の要望により
`sugoroku/` サブフォルダに同居させる。既存コードとは一切共有しない。

## 決定事項(利用者との合意)

| 項目 | 決定 |
|---|---|
| マス数 | 16 / 32 / 50 / 100 の4種類 |
| 難易度 | 優しめ / 普通 / 難しい / 鬼 の4段階。上がるほど飲む |
| 遊び方 | 1台を回して遊ぶ。プレイヤー名を登録し順番に振る |
| 人数 | 2〜8人 |
| サイコロ | 常に1個(1〜6) |
| 指令の種類 | 飲む系のみ(自分・指名・全員・一気)+ 休憩(指令なし) |
| 指令の決め方 | ゲーム開始時に毎回ランダム生成 |
| ゴール | ぴったり必要。超えた分はゴールで折り返して戻る |
| 終了条件 | 全員がゴールするまで続ける。途中終了ボタンもある |
| 形態 | `sugoroku/index.html` の単一ファイル。外部ライブラリなし |

## 難易度

難易度は「マスの配分」と「1回に飲む量」の両方に効く。

### 1回に飲む量

利用者の指定: 優しめ=グラス3分の1、普通=グラス2分の1、難しい=グラス一気、鬼=全部ショット。

| 難易度 | `{drink}` (1人分の基本量) | `{double}` (一気マス用の重い量) |
|---|---|---|
| 優しめ | グラスの3分の1を飲む | グラスの3分の2を飲む |
| 普通 | グラスの半分を飲む | グラス1杯を飲む |
| 難しい | グラス1杯を一気! | グラス2杯を一気! |
| 鬼 | ショット1杯! | ショット2杯! |

指令文はテンプレートで持ち、`{drink}` / `{double}` を難易度の文言に置き換える。
例: 「右隣の人が{drink}」→ 優しめ「右隣の人がグラスの3分の1を飲む」、鬼「右隣の人がショット1杯!」

### マスの配分(指令マスに占める割合)

| 難易度 | 😌休憩 | 🍺自分 | 👉指名 | 🍻全員 | 🔥一気 |
|---|---|---|---|---|---|
| 優しめ | 40% | 30% | 20% | 10% | 0% |
| 普通 | 25% | 30% | 25% | 12% | 8% |
| 難しい | 12% | 30% | 28% | 15% | 15% |
| 鬼 | 0% | 25% | 30% | 20% | 25% |

割合から個数を出す際は最大剰余法(端数の大きい順に1個ずつ追加)を使い、合計が指令マス数と一致するようにする。

## ボード

- マスは `0 〜 N-1` の N 個。`0` = START、`N-1` = GOAL。`1 〜 N-2` が指令マス(N-2 個)。
- 駒は 0 から始まり、GOAL(N-1)にぴったり止まったらゴール。
- 各マスは `{ index, cat, text }`。`cat` は `rest | self | pick | all | chug`。START/GOAL は `cat: 'start' | 'goal'`、休憩は `text` なし。

### 生成アルゴリズム

1. 難易度の配分からカテゴリ別個数を決める(最大剰余法)。
2. カテゴリの並びをシャッフルして `1 〜 N-2` に割り当てる。
3. 制約を満たすまで再シャッフル(最大200回。満たせなければ最後の結果を使う):
   - 一気(`chug`)マス同士は隣接しない。
   - マス `1 〜 3` には一気・全員を置かない(スタート直後は軽め)。
4. カテゴリごとに文言プールをシャッフルして順に配る。プールを使い切ったら再シャッフルして続ける(同じ文言は極力重複しない)。
5. `{drink}` / `{double}` を難易度の文言に置換する。

文言プールは `self` 12種以上、`pick` 14種以上、`all` 6種以上、`chug` 6種以上。
一部の文言は「もう1回サイコロを振る」を含む(`extraDice: true`)。その場合、指令カードに
「サイコロを振る」ボタンを出し、出た目を表示する(駒は動かない)。

乱数は関数として注入できるようにし(`rng()` が `[0,1)` を返す)、テストでは固定シードの疑似乱数を使う。

## ゲーム進行(ロジック層)

純粋関数のみ。DOM・localStorage に依存しない。`Sugoroku` オブジェクトとして公開する。

### 状態

```
{
  version: 1,
  size: 16 | 32 | 50 | 100,
  difficulty: 'easy' | 'normal' | 'hard' | 'oni',
  board: [ { index, cat, text?, extraDice? }, ... ],
  players: [ { name, color, pos, rank } ],   // rank: null(未ゴール) または 1,2,...
  turn: 0,            // players の添字。常に未ゴールのプレイヤーを指す
  phase: 'play' | 'result',
  nextRank: 1,
  lastMove: null | { player, roll, from, to, path, bounced, finished }
}
```

### 関数

- `createGame({ size, difficulty, names, rng })` → 状態。名前は trim し、空なら「プレイヤーN」。2〜8人以外は例外。
- `applyRoll(state, roll)` → 新しい状態(元の状態は変更しない)。
  - `to = pos + roll`。`to > goal` なら `to = goal - (to - goal)`(折り返し)。
  - `path` は通過マスの配列(折り返しを含む。例: 残り2で5なら `[+1, +2(goal), +1, 0, -1]` の順)。
  - `to === goal` なら `rank = nextRank` を付け、`nextRank++`。
  - `lastMove` に結果を入れる。`turn` はこの時点では進めない(指令カードを見せるため)。
- `endTurn(state)` → 次の未ゴールプレイヤーに `turn` を進める。全員ゴール済みなら `phase = 'result'`。
- `finishEarly(state)` → 途中終了。未ゴールの人を位置の降順(同位置は手番順)で残りの順位に入れ、`phase = 'result'`。
- `ranking(state)` → `rank` 順のプレイヤー配列(結果画面用)。
- `generateBoard(size, difficulty, rng)` → ボード配列。
- `DIFFICULTIES` / `SIZES` の定義(表示名・配分・文言)。

## UI(表示層)

3画面を1つの HTML で切り替える。スマホ縦持ちを優先し、PCでも崩れない。配色はバーの暗さに合わせたダーク1種。

### 1. セットアップ画面

- マス数をカード4枚から選択(16 / 32 / 50 / 100)。
- 難易度をカード4枚から選択(優しめ / 普通 / 難しい / 鬼)。各カードに量の目安を小さく表示。既定は「普通」。
- プレイヤー名の入力欄(初期2行、「＋追加」で最大8、各行に削除)。前回の名前を localStorage から復元。
- 「ゲームスタート」ボタン。
- 進行中のゲームが保存されていれば上部に「前回の続きがあります [続きから] [破棄]」。
- 注意書き: 「飲めない人はソフトドリンクでOK。無理な飲酒は絶対にしない。100マス×鬼はかなりの量です。」

### 2. ゲーム画面

- 上部固定: 「○○さんの番」(プレイヤー色付き)、サイコロの大ボタン、順位ミニ表示、「終了」ボタン。
- ボード: 蛇行グリッド(1行目は左→右、2行目は右→左…)。START が上、GOAL が下。
  - 列数: 16 → 4列。32 → 幅700px未満は4列、以上は8列。50/100 → 幅700px未満は5列、以上は10列。リサイズで再配置。
  - 各マス: 番号(START/GOAL は文字)、カテゴリのアイコンと色。
  - 駒: プレイヤー色の丸に名前の先頭1文字。同じマスに複数いれば小さく並べる。
  - マスをタップすると指令文を吹き出しで表示(事前に見てドキドキ)。
- サイコロを振る: ボタン押下 → 約0.8秒の目が回る演出 → 駒を1マスずつ(約0.25秒/マス)進める(折り返しも1マスずつ戻す)→ 指令カードを全画面で表示。
  - 休憩マス: 「😌 休憩。セーフ!」
  - ゴール: 「🏁 ○○さん、N着でゴール!」
  - 折り返し: カードに「ゴールで折り返し!」の一言を添える。
  - `extraDice` の指令: カード内に「サイコロを振る」ボタンと出目表示。
- カードの「OK!」で `endTurn` → 次の人へ。全員ゴールなら結果画面へ。
- 現在の駒が画面外なら自動でスクロール。
- 「終了」ボタンは確認ダイアログのあと `finishEarly`。

### 3. 結果画面

- 順位表(1着〜)。最下位には「🍻 最下位! 罰ゲームは皆で決めてね」程度の軽い一言。
- 「同じメンバーでもう一度」(設定画面に名前を保持したまま戻る)、「最初から」。

### 永続化

- `localStorage['sugoroku.v1.game']`: 進行中の状態(JSON)。`applyRoll` / `endTurn` のたびに保存。結果画面で削除。
- `localStorage['sugoroku.v1.setup']`: 最後に使ったマス数・難易度・名前。
- 読み書きは try/catch で包み、使えなくてもゲームは動く。

## エラー処理

- 名前が全て空 → 「プレイヤー1」「プレイヤー2」…を補う。
- localStorage の JSON が壊れている → 無視して新規扱い。
- 保存データの `version` が違う → 無視。

## テスト

### ロジック(`sugoroku/test/game.test.mjs`、`node --test`)

`index.html` を読み、`<script id="sugoroku-logic">` の中身を `vm` で評価して `Sugoroku` を取り出す。

- ボード生成: 長さ、START/GOAL、カテゴリ個数が配分と一致、一気の非隣接、1〜3に一気・全員なし、指令マスに文言あり、`{drink}` が残っていない、難易度ごとの文言置換(鬼なら「ショット」を含む)。固定シードで4サイズ×4難易度×複数シードを検査。
- `createGame`: 位置0、`turn 0`、名前の補完、人数の検証。
- `applyRoll`: 通常移動、ぴったりゴールで順位付与、超過時の折り返し位置と `path`、折り返し先の指令、元の状態を変更しない。
- `endTurn`: ゴール済みをスキップ、全員ゴールで `result`。
- `finishEarly`: 位置順で順位付け。
- 保存/復元: `JSON.stringify` → `parse` で同じ状態として動く。

### 画面(`sugoroku/test/e2e.test.mjs`、Playwright)

- セットアップ → 3人・16マス・普通で開始 → 振る → 指令カードが出る → OK → 手番が替わる。
- 4サイズのスクリーンショットを撮って見た目を確認する(スクリーンショットはリポに含めない)。

## 配布上の注意

## 追記(2026-11-05): ビジュアルとキャラクター

利用者の要望で、初版のダーク配色から「桃鉄風」の明るい配色に変更し、キャラクター選択を追加した。

- 配色: 空色の背景と流れる雲、緑の地図パネル、クリーム色のパネルに太い紺の縁取りとずらし影。
- ボード: マスは色帯付きの駅風。蛇行の向きに線路(紺地に黄色の中央線)でつなぐ。
- マスのアイコン・サイコロ・キャラクターはすべてインラインSVG/CSSで描く(画像ファイルなし)。
- キャラクター: 日本の昔話をモチーフにしたオリジナル12体(ももたろう・きんたろう・うらしまたろう・かぐやひめ・
  いっすんぼうし・あかおに・あおおに・いぬ・さる・きじ・かっぱ・びんぼうがみ)。桃鉄の公式デザインは使わない。
- ロジック: `CHARACTERS`(id と表示名)を公開し、`createGame` が `chars` を受け取る。未指定なら先頭から順に割り当て、
  人数不一致・不明な id・重複は例外。プレイヤーは `char` を持つ。
- セットアップ: 各プレイヤーの顔をタップするとピッカーが開く。他の人が選んだキャラは選べない。`chars` も保存する。
- 表示: 駒・手番表示・順位チップ・指令カード(喋っている風の吹き出し)・結果の表彰台(上位3人)にキャラを出す。
  ゴール時は紙吹雪。
- テスト: キャラの割り当てと検証(ロジック)、ピッカーで選んだキャラが駒と手番表示に出ること(画面)を追加。

## 追記(2026-11-05 その2): サイコロの場面・キャラ選択画面・2人ゴールで終了

- 終了条件を「全員ゴール」から「**2人がゴールしたら終了**」に変更(`GOALS_TO_END = 2`)。`endTurn` がゴール済み人数を見て、
  残りの人に位置順の順位を付けて `result` にする。2人プレイでは従来どおり2人目のゴールで終了。
- キャラ選択は専用画面にした。スタートを押すと1人目から順に「○/○人目: ○○さんのキャラクター」が出て、タップで次の人へ。
  先に選び終えた人のキャラだけ選べない(後の人の仮キャラは選べ、重なったら仮キャラを振り直す)。
  セットアップの顔をタップした場合はその人だけ選び直してセットアップに戻る。「同じ設定でもう一度」は選択をとばす。
- サイコロは「器に投げ込む場面」に変更。CSSの立方体(6面)を Web Animations API で落下→3回跳ねる→出目を正面に向けて静止させる。
  器は前後2枚のパーツで、前の縁がサイコロの下部を隠して中に入って見える。跳ねるたびに Web Audio で合成した「カッ」を鳴らす
  (右上の🔊で消音、設定は保存)。場面のタップで演出を飛ばせる。指令内の「もう1回振る」も同じ場面を使う。
- マスを立体ブロック風に変更: 種類色の薄い地、上の色帯、白い丸台の上にアイコン、左上に黄色の番号シール、下に厚みの影。
  一気マスは縞の帯と光るアイコン。芝生に花のドット。
