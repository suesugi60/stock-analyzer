# 飲みスゴロク

飲み会の場で、1台のスマホ(またはPC)を回しながら遊ぶスゴロク。
`index.html` を開くだけで動きます。サーバー・ネット接続・インストールは不要です。

> 飲めない人はソフトドリンクでOK。無理な飲酒は絶対にしないこと。

## 遊び方

1. `index.html` をブラウザで開く(スマホならファイルを共有して開くか、どこかに置いて URL で開く)。
2. **マス数**(16 / 32 / 50 / 100)と**難易度**(優しめ / 普通 / 難しい / 鬼)を選ぶ。
3. プレイヤー名を入力(2〜8人)して「ゲームスタート」。ひとりずつ順番にキャラクターを選ぶ(セットアップの顔をタップしても選び直せる)。
4. 手番の人が「サイコロを振る」を押す。器にサイコロが投げ込まれ、跳ねて止まった目だけ駒が進み、止まったマスの指令が大きく出る(演出はタップで飛ばせる。音は右上の🔊で消せる)。
5. 指令を実行したら「OK!」で次の人へ。
6. **ゴールはぴったり**。超えた分はゴールで折り返して戻り、戻った先の指令を実行する。
7. **2人がゴールしたら終了**。残りの人は進んでいる順で順位が付き、結果発表へ。途中でやめたいときは右上の「終了」。

マスをタップすると、そのマスの指令を事前に見られます。
ページを閉じたり再読み込みしても「続きから」で復帰できます(ブラウザの保存領域を使用)。

## 難易度

| 難易度 | 1回に飲む量 | 😌休憩 | 🍺自分 | 👉指名 | 🍻全員 | 🔥一気 |
|---|---|---|---|---|---|---|
| 優しめ | グラスの3分の1 | 40% | 30% | 20% | 10% | 0% |
| 普通 | グラスの半分 | 25% | 30% | 25% | 12% | 8% |
| 難しい | グラス1杯を一気 | 12% | 30% | 28% | 15% | 15% |
| 鬼 | 全部ショット | 0% | 25% | 30% | 20% | 25% |

- 🔥一気マスは「量が2倍」や「複数人で」の重い指令。難易度に関係なく隣り合わないように配置。
- スタート直後の3マスには一気・全員を置かない。
- マスの指令はゲーム開始のたびにランダムに組み直される。

## キャラクター

日本の昔話をモチーフにしたオリジナルの12体。すべて `index.html` 内のインラインSVGで、画像ファイルはありません。

ももたろう・きんたろう・うらしまたろう・かぐやひめ・いっすんぼうし・あかおに・あおおに・いぬ・さる・きじ・かっぱ・びんぼうがみ

同じキャラは1ゲームに1人まで。スタート後にひとりずつ順番に選び、選んだキャラが駒・手番表示・サイコロの場面・指令カード・表彰台に出ます。
絵を変えたいときは `SugorokuArt.CHAR_ART`、マスのアイコンは `SugorokuArt.ICON_ART` を編集してください。

## ファイル構成

```
sugoroku/
  index.html          アプリ本体(ロジック + 画面。これ1つで動く)
  README.md           このファイル
  test/
    helpers.mjs       index.html からロジック部分を取り出すヘルパー
    board.test.mjs    ボード生成のテスト
    game.test.mjs     サイコロ・移動・ゴール・順位のテスト
    e2e.test.mjs      画面のスモークテスト(Playwright)
```

`index.html` の中は `<script id="sugoroku-logic">`(純粋関数のゲームロジック)、`SugorokuArt`(キャラとアイコンのSVG)、
表示層スクリプトの3つに分かれています。指令の文言を変えたいときは
ロジック側の `TEXTS` を編集してください。`{drink}` と `{double}` は難易度ごとの量に置き換わります。

## テスト

Node.js 22 以上。

```bash
node --test 'sugoroku/test/board.test.mjs' 'sugoroku/test/game.test.mjs'
```

画面のテストは Playwright と Chromium が必要です。

```bash
node --test sugoroku/test/e2e.test.mjs
```

## 注意(このリポジトリの同期について)

`publish_public.sh` は Dropbox 側の元フォルダから `rsync --delete` でこのリポジトリへ同期します。
GitHub 側にだけ `sugoroku/` と `docs/` があると、次回の同期で削除されます。
残したい場合は元フォルダにも `sugoroku/` と `docs/` をコピーしてください。
